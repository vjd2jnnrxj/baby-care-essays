# 小儿调养丨孩子出现发热、怕冷？提示身体什么问题呢？

> 更新时间：2026-09-11 (UTC+8)

恶寒

发热

表证

恶寒发热，是表证的特征性症状。

春季多风，人们易感受风邪，风邪无孔不入，常常与他邪气共同致病，是诸多外感因素的“带头大哥”，寒、暑、湿、燥、火等邪气大多是借助风邪而侵及人体的，形成风寒、风温、风热、风燥和风湿等疾病，或出现更复杂的情况。
风邪袭表，侵犯人体表的卫阳，易出现恶寒的表现。随着疾病的进展，可能会出现发热的症状，就呈现出恶寒发热同时存在的情形。
《医碥·问证》说：“外感则寒热齐作而无间，内伤则寒热间作而不齐”。恶寒发热同时存在是表证的特征。

0

**1**

**外感风寒**

恶寒发热同时存在，怕冷，无汗，不想喝水，咽不红，舌色与平时差别不大，苔白，脉浮紧。显现出来的都是寒象症状，没有其他热象症状。

推拿可选取有祛风散寒、解表发汗等功效的穴位，如头面四大手法、揉风池、推三关等。

0

**2**

**外感风热**

恶寒发热同时存在，有汗，口渴喝水，咽红或肿，舌尖红，苔白，脉浮数。显现出来的寒象症状与热象症状都有。

推拿可选取有祛风、解表发汗、清热等功效的穴位，如头面四大手法、掐二扇门、清天河水、清肺经等。

0

**3**

**温病**

初起时恶寒发热同时存在但只微恶寒，很快发展到只发热、怕热，起病时即口渴喜喝水，咽红肿或不红肿，舌红，苔腻，脉数。

推拿可选取解表（有恶寒时）、清热、滋阴的穴位，如退六腑、取天河水、推脊、清肺经等。

热证常见症状表现有精神亢奋，脾气大，烦躁，面色红，舌红，苔黄，苔干，咽红肿痛，口腔溃疡红肿痛，口气臭，口渴喜喝水、凉水，喜凉，恶热，涕稠浊，涕黄，痰黄，痰稠，汗臭，小便黄、短、涩痛，矢气臭，大便干或便秘，大便臭秽，脉数、脉洪等。

寒证常见症状表现就是热证的对立面，是相对的。

疾病性质有寒证、热证之分，平时所见的发烧，却不一定都等于是热证，发烧只是一个症状，它可以由寒证或者热证引发，因为寒、热证都可以导致身体发生系列临床症候变化。在分清疾病的寒热后，治疗原则可以参考“寒（病）者热（治）之，热（病）者寒（治）之”。

**注意事项**

1. 如果持续多日发烧未退，或出现高热或超高热，则需前往医院就诊。

2. 发烧伴有呕吐、拉肚子、抽搐、惊厥、精神不佳等情况，也要尽快到医院就诊。

**推拿**

**开天门**

【定位】：在两眉头连线的中点，往上直到前发际，呈一条直线。【操作】：用两个拇指或以中指为主、食指和无名指为辅，自下而上交替直推。

**推坎宫**
【定位】：从眉头起至眉梢，呈一条直线，左右对称。【操作】：用两个拇指从眉头同时向眉梢分推。

**揉太阳**
【定位】：在眉梢延长线与外眼角延长线连线交点后方凹陷处。【操作】：用中指在这个穴位逆时针按揉。

**揉耳后高骨**
【定位】：在耳朵后方高骨下方的凹陷处。【操作】：用拇指或中指在这个穴位上按揉。

**清天河水**
【定位】：在前臂内侧正中，从腕横发烧持续41度及以上需前往医院就诊纹到肘横纹呈发烧持续41度及以上需前往医院就诊一条直线。【操作】：用食、中指面从腕横纹向肘横纹直推。

**取天河水**
【定位】：在前臂内侧正中，从腕横纹到肘横纹呈一条直线。【操作】：用食、中指面从肘横纹向腕横纹直推。

**推三关**
【定位】：在前臂桡侧缘，从腕横纹到肘横纹呈一条直线。【操作】：用拇指桡侧缘或食、中指面从腕横纹向肘横纹直推。

**退六腑**
【定位】：在前臂尺侧缘，从腕横纹到肘横纹呈一条直线。【操作】：用拇指桡侧缘或食、中指面从肘横纹向腕横纹直推。

**揉风池**

【定位】：在项部，当枕骨之下，与风府相平，胸锁乳突肌与斜方肌上端之间的凹陷处。

【操作】：用双侧拇指或拇指、食指在这个穴位上按揉。

**掐揉二扇门**

【定位】：掌背中指根本节两侧凹陷处。

【操作】：用两手食、中二指固定小儿腕部，令手掌向下，无名指托其手掌，用两拇指甲掐之，继而揉之。

**清肺经**

【定位】：在无名指螺纹面。

【操作】：从指根向指尖直推。

**推脊**

【定位】：在后背正中线上，从第七颈椎棘突下（大椎穴）到尾椎骨端，呈一条直线。

【操作】：以食、中两指螺纹面自上而下直推。
